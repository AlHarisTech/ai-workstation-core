## 3. ⚙️ TypeScript Interfaces (جاهزة للتنفيذ)

```typescript
export type MCPActionType =
  | "git"
  | "filesystem"
  | "memory"
  | "github"
  | "fetch"
  | "context7";

export interface MCPAction {
  type: MCPActionType;
  operation: string;
  version: "1.0";
}

export interface MCPContext {
  tenant_id: string;
  session_id: string;
  trace_id: string;
  workspace: {
    path: string;
    repo: string;
  };
}

export interface MCPRequest {
  id: string;
  timestamp: string;
  source: "opencode";
  type: "mcp.request";
  action: MCPAction;
  context: MCPContext;
  payload: {
    resource: string;
    parameters: Record<string, any>;
  };
  auth: {
    type: "bearer" | "api_key" | "mcp_signed";
    scope: string[];
  };
  policy: {
    allow: string[];
    deny: string[];
  };
  meta: {
    priority: "low" | "medium" | "high" | "critical";
    timeout_ms: number;
    retry: number;
    trace_id: string;
    span_id: string;
  };
}
```

## 4. 🧠 Validation Rules (STRICT MODE)

### Rule 1 — Action Validation
Reject if:
- `action.type` not in MCPActionType
- `operation` is empty

### Rule 2 — Policy Enforcement (Fail Closed)
- If `deny` matches action → REJECT
- If `allow` missing match → REJECT

### Rule 3 — Context Integrity
- `session_id` required
- `trace_id` required
- `workspace.path` required

### Rule 4 — Execution Safety
- `timeout_ms` max = 120000
- `retry` max = 3

## 5. 🧭 Gateway Routing Logic (FINAL FORM)

```
step 1 → validate request
step 2 → enforce policy
step 3 → resolve capability (server map)
step 4 → route to MCP server
step 5 → normalize response
step 6 → attach trace metadata
return response
```

## 6. 🔌 MCP Plugin Model (STATIC RULE)

كل MCP Server يجب أن يعلن:

```json
{
  "server": "git",
  "capabilities": [
    "commit",
    "push",
    "branch"
  ],
  "version": "1.0"
}
```

## 7. 🧱 Execution Contract Rule

Gateway لا ينفذ أي منطق عمل:

- لا Git logic
- لا filesystem logic
- لا memory logic

فقط:

```
validate → route → normalize
```

## 8. 🧾 FINAL SYSTEM DEFINITION

```
OpenCode
  ↓
MCP Gateway (Validation + Routing + Policy + Normalization)
  ↓
MCP Plugin Servers (Execution Only)
```
